# Source notes

Source: Yuval Avidani, "איך קלוד אופוס 5.5 יודע לפתח בתלת מימד כ"כ טוב? בואו נעשה סדר בבלאגן, מההתחלה." Published September 28, 2026. [YouTube](https://youtu.be/yhjouIJY6ko).

The video walks through a browser game project, its folders, assets, models, textures, user interface, audio, video, and web deployment. It also shows two adjacent examples: a 3D hero on a website and an interactive camera-angle explainer.

This lab carries those ideas into three short browser games:

1. **Skyline** turns the city-flight example into a ring-collection route.
2. **Last Orbit** uses the same movement-and-collection vocabulary in a space scene.
3. **Motion Director** turns the camera-motion explainer into a timed composition challenge.

## Practices taken from the video

- Map models, textures, sound, video, user interface, and code to clear project locations.
- Connect each asset to a scene and to the game loop that uses it.
- Review live screenshots before sending a public game link.
- Use player feedback to decide the next change.
- Keep API keys inside the project that owns them; never search other projects for credentials.
- Set a spend limit before making paid asset or audio requests.

The video reports that the creator's project took about six hours and four prompts. The number is treated as a source anecdote, not a target or estimate for this project.
